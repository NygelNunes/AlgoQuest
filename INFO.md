# AlgoQuest

## Backend (Java + Spring Boot, Maven)
Requer JDK 17+ e Maven.

    mvn spring-boot:run

API em http://localhost:8080/api

## Frontend (HTML/CSS/JS puro)
Abra a pasta `frontend/` no VS Code e rode com a extensão **Live Server**
(ou `npx serve frontend`). Ele chama o backend em `frontend/js/api.js` (`API_URL`).
